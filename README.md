# Hon'yaku — JP ⇄ EN travel translator

Offline-first web app (PWA). Open it once online, then "Add to Home Screen" — works offline after that.

- **Phrasebook** (offline): Basics, Food & Ordering, Clothes & Shopping, Colors, Getting Around, Hanging Out, Numbers, Emergency — each with casual (21-y/o vibe) and polite versions + romaji.
- **Translate anything**: phrasebook match first, then free online translation (no API key, no AI) with casual-ization; offline word-by-word fallback.
- 🔊 speak, 🎤 voice input, 🖥 big "show to staff" mode, ⭐ saved, 🕘 history.

Live at: `https://smaxhy.github.io/secret-weapon/` (Settings → Pages → Source: GitHub Actions).
